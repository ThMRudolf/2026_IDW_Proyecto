# Concert Manager Dashboard

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación web interactiva orientada a la gestión y visualización de conciertos y artistas. La plataforma permite a los usuarios visualizar información relevante sobre eventos musicales, analizar métricas de popularidad y asistencia, así como planificar conciertos de manera estructurada.

El sistema integra visualización de datos, consumo de APIs y herramientas interactivas, con el objetivo de ofrecer una experiencia intuitiva y funcional para la toma de decisiones.

---

## Objetivo

Desarrollar un dashboard interactivo que permita:

- Visualizar artistas y conciertos  
- Analizar métricas de popularidad y asistencia  
- Planificar eventos mediante un calendario  
- Visualizar ubicaciones de conciertos en un mapa interactivo  

---

## Funcionalidades principales

- Visualización de artistas con métricas de popularidad  
- Tabla de conciertos con información detallada  
- Gráfica de popularidad utilizando Chart.js  
- Mapa interactivo de ciudades de gira (Leaflet)  
- Calendario de conciertos (FullCalendar)  
- Formulario para agregar conciertos  
- Persistencia de datos mediante localStorage  
- Tema claro/oscuro con persistencia  
- Consumo de datos mediante fetch (API simulada / externa)

## Fundamentación del diseño visual

El diseño visual del sistema se desarrolló considerando principios de experiencia de usuario (UX) y visualización de datos, donde el color cumple un papel fundamental en la interpretación y jerarquización de la información.

En este contexto, los tonos azules son ampliamente utilizados como base visual debido a su asociación con conceptos como confianza, estabilidad, seguridad y precisión. Desde la psicología del color, el azul genera una percepción de control y profesionalismo, lo cual resulta fundamental en sistemas donde el usuario interactúa con datos o toma decisiones basadas en información. Además, su uso contribuye a la claridad visual y a la organización de la interfaz, facilitando la lectura y reduciendo la carga cognitiva. Asimismo, la presencia constante del azul en plataformas tecnológicas ha generado una familiaridad en los usuarios, permitiendo que este tipo de interfaces sean percibidas como intuitivas y confiables desde el primer contacto.

Por otro lado, la incorporación de tonos vibrantes como rosa responde a la necesidad de introducir dinamismo visual y evitar una interfaz excesivamente rígida. Estos colores están asociados con creatividad, energía y expresión, por lo que son particularmente utilizados en industrias relacionadas con el entretenimiento y la cultura. Su uso en combinación con una base más neutra permite generar contraste visual sin comprometer la legibilidad, además de aportar una identidad más atractiva y contemporánea.

En cuanto a los colores neutros, como blanco, gris y negro, estos cumplen una función estructural dentro del diseño. Su principal objetivo es mejorar la legibilidad, reducir la saturación visual y permitir que los elementos clave destaquen. En interfaces con alta densidad de información, el uso adecuado de estos tonos es fundamental para evitar sobrecarga cognitiva y facilitar la navegación del usuario.

Finalmente, la inclusión de modo claro y modo oscuro en interfaces digitales se fundamenta en criterios de accesibilidad y ergonomía visual. La posibilidad de alternar entre estos modos permite adaptar la interfaz a diferentes condiciones de iluminación y preferencias del usuario, reduciendo la fatiga visual y mejorando la experiencia general. Este tipo de funcionalidad se ha convertido en una práctica estándar en aplicaciones modernas, al priorizar la personalización y comodidad del usuario.
