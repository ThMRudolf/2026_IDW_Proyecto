# Concert Manager Dashboard

## Descripción del proyecto

Este proyecto es una aplicación web desarrollada como parte de la materia Introducción al Desarrollo Web.

La plataforma está enfocada en managers de música, permitiendo visualizar artistas, planificar conciertos y analizar estadísticas como popularidad y asistencia.

El proyecto integra frontend, consumo de APIs y herramientas de visualización de datos.



## Funcionalidades principales

* Visualización de artistas
* Planeación de conciertos mediante calendario
* Visualización de ubicaciones en mapa
* Gráficas de popularidad y asistencia
* Modo claro / oscuro persistente
* Uso de localStorage para almacenamiento de datos
* Consumo de API (Spotify o datos simulados)

## Cómo ejecutar el frontend

1. Clonar el repositorio:

git clone https://github.com/ThMRudolf/2026_IDW_Proyecto.git

2. Abrir la carpeta en Visual Studio Code

3. Ejecutar con Live Server o abrir index.html en el navegador

---

## Cómo ejecutar el backend 

1. Instalar dependencias:

pip install -r requirements.txt

2. Ejecutar el servidor:

python main.py
